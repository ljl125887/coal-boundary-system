# 公开发布范围与脱敏记录

## 纳入

| 范围 | 选择理由 |
|---|---|
| Python 算法、GUI、Worker 和集成源码 | 展示设计思路与工程能力 |
| 通用业务 JSON Schema | 解释数据契约，不含实际成果 |
| 纯合成测试和模拟服务测试 | 无需现场文件即可验证核心行为 |
| 数学数据生成示例 | 复现处理与缓存流程，原始输入不入库 |
| 重新撰写的技术文档与示例配置 | 脱离现场配置介绍算法和运行方式 |
| CI、忽略规则和发布检查脚本 | 持续验证并防止误传运行数据 |

## 排除

全部 LAS/LAZ、outputs、真实计算成果、现场 ROI 和 GeoJSON、台账/Excel、模型权重、缓存、日志、任务队列、临时测试目录、历史截图、迁移包、个人环境脚本、生产配置、原始联调和部署记录。未复制原项目 Git 历史。

## 处理方式

- GUI 的个人解释器绝对路径改为当前 Python 解释器。
- 现场总体积改为明确占位值，默认关闭参考评估与模型。
- 实测坐标和结果数值替换为独立构造的数学测试值。
- 依赖现场 LAS、台账和权重的测试改为合成文件或显式可选测试。
- 原有现场文档不发布，公开文档重新编写。
- 端点示例仅使用 localhost、回环地址和保留的 `.invalid` 测试域名。
- 原业务项目不修改；此目录是独立公开副本。

代码中的 EPSG、中央经线和假东等标准投影参数属于通用数学配置。测试中人为指定的坐标不是实际场站位置或实测轮廓。

## 许可状态

发布目的为技术展示与分析，尚未指定开源许可证；如需开放再使用权限，由维护者另行决定许可证。不得通过 Issue 或 PR 上传现场数据、凭据或内部日志。
